============================================================
このフォルダ（availability）の続きを Claude に頼むときの呼び出し方
============================================================

Claude（Claude Code）に、次のどちらかの一言を入力するだけで OK です：

    ・「tour-info」
    ・「空き状況ページの続き」

どちらの言い方でも Claude が気付いて、memory を読み直し、
配信中の tour-info リポジトリ（GitHub Pages）と
このフォルダの index.html の現在の状態を把握した上で
前回の続きから着手します。
