# Googleカレンダー運用ルール

## 1. 勤務登録イベント

勤務登録は「タイトル」で判定する。

---

### 出勤例

```txt
砂川〇 09:30-18:00
```

```txt
畑中〇 09:30-14:00
```

---

### 休み例

```txt
砂川✖
```

```txt
畑中✖
```

---

## 2. 予約済みイベント

予約済み判定は、
イベントタイトルではなく「説明欄(description)」を使用する。

タイトルは自由。

---

### 説明欄例

```txt
参加スタッフ：
砂川、畑中
```

---

## 予約済み判定

説明欄にスタッフ名が含まれている場合、
そのイベント時間中は該当スタッフを予約済み（OFF）扱いにする。

---

# 判定優先順位

1. Manual Lock = TRUE
   → 一切変更しない

2. ✖ / OFF
   → 終日 Off

3. 予約済みイベント重複
   → 該当時間帯 Off

4. 勤務時間不足
   → Off

5. 問題なし
   → Available

---

# 判定ルール

## 勤務時間判定

スタッフ終了時刻 >= ツアー終了時刻

→ Available

それ以外

→ Off

---

## PM判定

PM判定は実際のツアー終了時刻を基準とする。

例：

* PMツアー 14:00-15:00
  → 15:00 まで勤務なら Available

* PMツアー 14:00-17:00
  → 17:00 まで勤務必要

---

## 重複判定式

以下を満たす場合は重複：

```txt
eventStart < tourEnd
AND
eventEnd > tourStart
```
